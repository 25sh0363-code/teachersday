✏️ A Class Act — Teachers’ Day

13 teachers. 10 subjects. 1 class. ∞ patience.

A handcrafted interactive Teachers’ Day experience built for XII-Innovators — turning a simple thank-you into a little digital classroom of its own.

Instead of another static greeting, A Class Act transforms the memories, personalities, and gratitude of an entire class into an interactive experience inspired by chalkboards, notebooks, school registers, and the periodic table.


✨ What’s Inside

* 🧑‍🏫 Interactive Chalkboard Hero — write directly on the board with selectable chalk and erase your masterpiece.
* 🧪 The Elements of Our Classroom — every teacher becomes a custom “element” with their own subject, personality, and message.
* 📚 Faculty Showcase — teachers are presented through classroom-inspired cards and illustrations.
* 📋 Interactive Register — mark teachers as present and watch the class fill up.
* 💌 Digital Thank-You Card — sign the card and seal it with your name.
* 🎉 Gratitude Engine — shower the page with appreciation and trigger a little celebration.
* ✍️ Chalk-drawn animations — illustrations reveal themselves as you scroll.
* 📜 Scroll-based storytelling — the entire page unfolds like walking through a beautifully designed school day.
* 📱 Responsive design — built to work across desktop and mobile.

🎨 Design Philosophy

The entire experience is built around one idea:

Make the website feel like something that belongs in a classroom.

Paper textures, wooden boards, handwritten typography, chalk animations, school registers, taped-up cards, stamps, formulas, and notebook-style layouts all work together to create that feeling.

Even the typography is deliberately split between:

* Fraunces — editorial/classic
* Caveat — handwritten/chalk-like
* Space Mono — technical/classroom labeling

🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript
* Canvas API
* SVG
* Intersection Observer API
* Lucide Icons
* Google Fonts

No framework. No build system. Just the browser.

🧠 Interactive Details

The page isn’t just animated — it reacts to the visitor.

Cards can be flipped, chalk can be selected, the board can be written on, sections reveal themselves while scrolling, signatures can be added, and the final appreciation interaction triggers a celebration.

The goal was to make the user participate in the tribute, rather than simply read it.

❤️ Made For

XII-Innovators

For the teachers who taught more than what was on the timetable — and for a class that wanted to say thank you in a way that felt a little more memorable.

No homework was assigned in the making of this page.
